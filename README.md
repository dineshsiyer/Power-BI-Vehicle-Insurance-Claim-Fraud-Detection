# Vehicle Insurance Claim Fraud Detection Dashboard

This repository contains a Power BI dashboard designed for EDA on vehicle insurance claims. The project leverages a publicly available dataset from Kaggle to explore patterns, trends, and anomalies that may indicate fraudulent activity.

## Overview

Insurance fraud detection is a critical task that helps insurers reduce losses and improve risk management. This dashboard aims to:
- Visualize key metrics related to vehicle insurance claims.
- Identify trends and outliers that could indicate potential fraud.
- Provide actionable insights for further investigation.

## Data Source

The dashboard uses data from the [Vehicle Claim Fraud Detection dataset on Kaggle](https://www.kaggle.com/datasets/shivamb/vehicle-claim-fraud-detection). This dataset includes various attributes related to insurance claims that allow for detailed analysis and visualization.

## Features

- **Interactive Visualizations:** Explore different dimensions of the data with interactive charts and graphs.
- **Fraud Indicators:** Highlight factors and trends that may suggest fraudulent claims.
- **Drill-Down Analysis:** Filter and zoom into specific segments for deeper insights.
- **User-Friendly Interface:** Designed with ease-of-use in mind for both business users and data professionals.
